# Kern has moved

The active Kern repository is now **gradigit/kern**.

Kern is a fully native macOS WYSIWYG Markdown editor built with Swift, AppKit, and TextKit.

This repository is kept only as a public pointer because the `kerneditor` organization may become the project home later if Kern grows large enough to need a dedicated organization.

Use the active repository for source code, issues, releases, and documentation.
